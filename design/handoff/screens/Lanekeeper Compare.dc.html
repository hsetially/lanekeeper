1Compare · grid across swimlanes and whole-swimlane compare

Both modes live in one page; the switch at top right is live. The grid is a real virtualised list: 5,000 settings generated in the page, about 40 rows in the DOM, sticky header and sticky path column (scroll sideways: the grid is 74px wider than the viewport on purpose). Click two cells in a row to open the diff drawer. Every column header names the file that swimlane reads: filled blue chip = tenant file, outlined chip = base file.
